# 截图翻译：详细说明与开发文档

面向想了解全部细节、从源码运行或自己打包的人。普通使用看仓库根目录的 [README.md](../README.md)（[English](../README.en.md)）。下文的路径都相对仓库根目录。

按快捷键框选屏幕任意区域，译文**原位盖在原文上**，按空格一键切回原文对照。
服务链：**主服务 → 备用服务 → 腾讯兜底（默认关，可在设置里打开）→ 都失败只显示原文**。主服务、备用服务是你自己填的 OpenAI 兼容接口（DeepSeek、硅基流动、阿里云百炼、OpenAI、自建 vLLM 都行），每一层都可以不配置，没配置的跳过。
腾讯兜底是免 key 的第三层，只能在走完引导后到托盘「设置… → 翻译服务」里打开（引导要求测试连接通过，且没有腾讯选项）；打开后识别出的文字会发给腾讯，见下文「腾讯交互翻译」。

## 第一次使用

1. 建环境（只做一次）：
   ```
   conda create -y -n shotrans python=3.12
   conda activate shotrans
   python -m pip install -r requirements.txt
   ```
2. 双击 `启动截图翻译.bat`。托盘里出现蓝色的「译」字图标；第一次运行会自动弹出**引导**，四步：
   1. 选界面语言（中文 / English）；
   2. 检查 Windows 的 OCR 语言包（简体中文、英文两个都要；缺哪个有「打开系统语言设置」按钮）；
   3. 选翻译服务、填 key，点「测试连接」——测试通过「下一步」才可点，改了地址/模型/预设/key 任何一项都要重测；
   4. 确认快捷键（默认 `Ctrl+Alt+Q`，被占用会当场标红）和是否开机自启，最后「现在试一下」直接进入框选。
   - 引导中途关掉：右下角提示「还没配置翻译服务」，点提示重新打开；此时按快捷键也是打开引导。
   - 只会运行一个：已经在运行时再双击，会提示「截图翻译已在运行，按 快捷键 截图翻译」（图标可能收在托盘的 ^ 里）然后退出；快捷键直接读 `config.toml`，读不出来、写错了就不写快捷键。
   - 配置过以后手动启动：程序直接进托盘，弹一个提示「已在后台运行，按 快捷键 截图翻译；图标可能收在 ^ 里面」，点提示打开历史记录。第一次运行（弹引导）不弹；启动时已经有别的提醒（快捷键被占用、迁移结果、key 解不开、术语表读取失败、缺 OCR 语言包）也不弹——提示小窗只有一个，后一条会顶掉前一条，不能把这些提醒挤掉。开机自启（带 `--autostart`）不弹。
   - **所有提醒都是程序自己画的右下角小窗**（`shotrans/ui/notice.py`），不走 Windows 通知：关了通知、开了勿扰 / 专注助手照样看得到（以前用的是系统托盘通知，这些情况下会被系统直接吞掉，「快捷键被占用」「key 解不开」「缺 OCR 语言包」这类提醒用户一个都看不到）。小窗在主屏任务栏上方，不抢焦点、不进任务栏和 Alt+Tab；约 6 秒后自动消失，鼠标停在上面不消失；点它打开对应窗口（快捷键被占 → 设置的快捷键页，内部出错 → 自检…），点 × 只关掉；同一时间只有一个小窗，新提醒替换旧的。
3. 各预设去哪里拿 key（引导和设置里也有「去注册」按钮）：

   | 预设 | 默认地址 | 默认模型 | 关闭思考 | 取 key 的地址 |
   |---|---|---|---|---|
   | DeepSeek | `https://api.deepseek.com` | `deepseek-flash` | 默认勾上（`deepseek`） | https://platform.deepseek.com/api_keys |
   | 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | 不勾（该模型本来不思考） | https://cloud.siliconflow.cn/account/ak |
   | 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-flash` | 不勾（默认不思考） | https://help.aliyun.com/zh/model-studio/get-api-key |
   | OpenAI | `https://api.openai.com/v1` | `gpt-6-luna` | 默认勾上（`openai_reasoning`） | https://platform.openai.com/api-keys |
   | 自定义 | 任何 OpenAI 兼容接口（自建 vLLM、OpenRouter…）：自己填地址和模型 | | | |

   以上预设 **2026-10-14 按各家官方文档核实**（来源见 [预设核实-2026-10-14.md](预设核实-2026-10-14.md)）。各家会改版、换模型、调价：选了预设以后，地址和模型都可以自己改成官网最新的值；**价格一律以服务商官网为准**，程序里显示的只是核实当天的约数。
   - 百炼：key 按地域绑定、不通用；新加坡地域的账号把地址改成 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。官方现在推荐带业务空间 ID 的专属域名（`https://<业务空间ID>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`），旧地址官方写明仍可正常使用，所以预设沿用旧地址。

## 怎么用

- `Ctrl+Alt+Q`（可在设置里改；Ctrl+Alt+D 是有道词典的，会冲突）→ 框选 → 译文原地出现。识别耗时随框选面积变化，实测约 0.1～2.5 秒（小块文字零点几秒，整屏论文页 1～2.5 秒），之后译文一段一段地出现。
- 托盘菜单（左键单击图标 = 截图）：截图翻译（快捷键）/ 历史记录… / 设置… / 自检… / 重新加载配置 / 关于… / 退出。以前菜单里的「开机自启」「编辑术语表」「打开配置文件」现在都在「设置」里（配置文件在「设置 → 常规 → 打开数据文件夹」）。
- 浮窗里：

| 操作 | 效果 |
|---|---|
| `空格` | 整体切换原文 / 译文 |
| 鼠标停在某段上 0.5 秒 | 弹出这段的原文（原文视图下弹出译文；译文被截断时一并给出全文） |
| 双击某段 | 复制这段译文 |
| 右键截图里的空白处（截图里没有段落的地方、公式/数字这类跳过的段） | 立即关闭浮窗，钉住的也关（工具栏、截图外面多出的窗口部分不算；键盘上的菜单键也不算，都不关） |
| 右键某段 | 重翻这一段（换另一个翻译服务：按 主服务 → 备用 → 腾讯 的顺序取第一个不是当前服务、且可用的）/ 撤销重翻 / 复制原文 / 复制译文 |
| `Ctrl+C` / `Ctrl+Shift+C` | 复制全部译文 / 全部原文 |
| `D` | 强制反转翻译方向（中⇄英）并重翻 |
| 拖动 | 移动浮窗 |
| `Esc` | 关闭 |

- 鼠标移到浮窗上会出现工具栏：最左边的圆点表示这次用了哪个服务（绿 = 主服务，蓝 = 备用，紫 = 腾讯，红 = 都不可用；一张图里混用了几层时显示最差的那层），后面是 原/译、行/段、中⇄英、复制、📌钉住、关闭。主服务掉线期间（默认 60 秒内）跳过主服务直接走下一层，状态显示「备用（主服务掉线中）」或「腾讯（主服务掉线中）」；没配置主服务时不显示这个附注。
- 没钉住的浮窗：点到外面就关；再截一张会替换它（截屏时所有浮窗先藏起来，不会被截进新图；框选取消就原样放回）。钉住的浮窗可以同时开好几个。
- 某段右上角有琥珀色小三角：这段有需要留意的地方，鼠标停上去能看到原因。有两种情况：
  - **显示的是原文**：大模型（主服务、备用）把引用、数字等占位符弄丢了（「占位符丢失，显示原文」），或翻译服务不可用。翻译服务不可用时状态栏旁有「设置」链接，点开直接到设置的翻译服务页。
  - **显示的是译文，但引用/术语可能没保持原样**：腾讯两次弄丢占位符后，改用不带占位符的原文再翻一次，照常显示译文（「引用/术语可能未保持原样」）。这种译文不进缓存。
- 只框到公式/数字时，状态显示「只有公式/数字，未翻译」；什么字都没识别出来才显示「没有识别到文字」。
- 只装了英文 OCR 语言包时中文截图仍出结果，状态栏注明「未装简体中文 OCR 语言包」。

## 数据放在哪

全部在 `%APPDATA%\截图翻译\`（地址栏粘贴这个路径即可打开；托盘「关于…」里有「打开数据文件夹」按钮）：

| 文件 | 内容 |
|---|---|
| `config.toml` | 配置（每次保存前会把上一版留成一份 `config.toml.bak`，只留一份） |
| `术语表.txt` | 术语表 |
| `history.json` | 历史记录（默认最近 200 条）：每条的原文、译文；存了截图的记录另有 `image_id`（添加时写下）和 `images`（两张图都写成功后才补上：`{"original": 文件名, "rendered": 文件名}`） |
| `history_images\` | 历史记录的截图（「设置 → 常规 → 保存截图图片」，默认开）：每条两张 PNG，`<image_id>-original.png`（原图）、`<image_id>-rendered.png`（译文盖在原图上，和浮窗、调试快照里的 `rendered.png` 是同一张）。和记录同生同灭：同一张截图重翻（切 中⇄英、行/段）只留最新那对；超出条数、删除、清空时一起删；没有记录引用的孤儿文件在每次写历史后清掉——只在 history.json 读成功时清；读不出来（损坏改名 .bad、文件不见）时现有的图一张不删，挪进 `history_images\.kept-时间\`（挪不动就本次运行不再清理）。图在后台线程写，写失败只记日志，文字记录照常保留；旧的纯文字记录照常显示 |
| `logs\` | 日志 `shotrans.log`（滚动保存，最多约 4 MB） |
| `debug\` | 浮窗工具栏「导出」生成的调试快照 |

- **便携模式 / 换位置**：设置环境变量 `SHOTRANS_HOME` 指向任意文件夹，程序就把上面这些都放进去（测试也靠它隔离）。
- **从旧版本升级**：第一次启动时，如果数据目录里没有配置，而程序目录里有旧的 `config.local.toml`、`术语表.txt`、`history.json`，会自动复制过去，右下角提示「已把旧配置迁移到…」。**旧文件原样保留、一个字节都不改**，想退回旧版随时可以。复制失败的文件会在提示里列出来。旧配置读不出来（格式写错、值不对）时，术语表和历史照样复制过去，配置不迁移，提示迁移失败，点提示打开引导重新填写。旧格式（`[vllm]`/`[fallback]`）的配置读进来后，旧的 vLLM 对应「主服务」、`[fallback]` 对应「备用服务」，超时沿用旧默认值（连接 2、首字 3、断流 10 秒）；在设置里保存一次就换成新格式和新默认值。
- 程序目录里的 `config.local.toml` 不进 git（`.gitignore` 已写）；`config.example.toml` 是新格式的配置模板，可以对照着手写。

## 设置窗口

托盘「设置…」。五个标签页，点「确定」才保存并立即生效（不用重启），「取消」放弃：

- **翻译服务**：主服务、备用服务各一块——选预设（自动带出地址、模型、是否关闭思考）、填地址和 key、选模型（可点「获取模型」从接口读列表）、「测试连接」；领域提示（例如“计算机视觉方向的学术论文”，写进大模型提示词）；下面是腾讯兜底开关。地址必须写 `http://` 或 `https://`，不合格当场标红并停在这一页。
  - **关闭思考**：某些模型会先“思考”再回答，翻译用不上，只会变慢。勾上后按所选的「思考关闭方式」只发对应字段：自建 vLLM（`chat_template_kwargs`）发 `{"chat_template_kwargs": {"enable_thinking": false}}`；百炼、硅基流动（`enable_thinking`）发 `{"enable_thinking": false}`；DeepSeek 发 `{"thinking": {"type": "disabled"}}`；OpenAI（`openai_reasoning`）发 `{"reasoning_effort": "none"}`。不勾就一个字段都不发。公共 API 对未知字段可能报 400，所以别选不属于你那家的方式。
  - **key 加密**：key 用 Windows 的 DPAPI 加密后存在 `config.toml` 的 `api_key_enc` 里，**只有同一台电脑的同一个 Windows 用户能解开**。换电脑、换账号后要重填 key（设置里会提示“解不开”，并有「清除」按钮）。你手写在 `config.toml` 里的明文 `api_key` 也认，下次在设置里保存时自动改成加密并删掉明文。key 不会出现在日志、报错、自检结果和调试快照里。
- **快捷键**：点一下输入框，按下想要的组合；被别的软件占用会当场标红。
- **术语表**：见下一节。
- **常规**：界面语言（中文 / English，立即生效，已打开的窗口也跟着变）、开机自启（在当前用户的「启动」文件夹放一个快捷方式，不碰注册表；取消勾选即删除；快捷方式的参数带 `--autostart` 标记（打包版 `截图翻译.exe --autostart`，源码版 `pythonw -m shotrans --autostart`），这样启动不弹「已在后台运行」提示；勾着时每次「应用 / 确定」都会核对快捷方式是否指向当前这份程序（目标、参数、工作目录都比），移动过文件夹、从源码版换成 exe、旧版本建的没带标记的快捷方式都会被重写（所以老用户在点「应用」之前，开机时仍会看到启动提示）；试用模式（环境变量 `SHOTRANS_TRIAL`，「用临时数据目录启动.bat」会设）下这一项是灰的，程序不建也不删快捷方式）、历史保留条数、「保存截图图片」（`[history] save_images`，默认开；关掉后只存文字）、「打开数据文件夹」。
- **高级**：翻译分块与并发、各层超时（带「恢复默认」）。

**「重新加载配置」什么时候用**：你直接用记事本改了 `config.toml`（或术语表）以后，托盘点它立即生效。写坏了（TOML 语法错）会弹提示给出错误原文，旧配置继续用。

### 分块并发与超时（主服务、备用）

整屏长文如果合成一个请求，模型只能从头到尾顺序生成。现在按阅读顺序把段落切成几块，同时发出（设置 → 高级，或 `[translate]`）：`chunk_chars = 600`（每块约多少原文字符）、`chunk_max_segments = 8`、`max_concurrency = 4`（1 = 一块接一块）。

- 段落少（不到一块）时仍是一个请求。各块各自流式返回，每段一译完就出现；第一块先走一步，其余块等它译出第一段（最多 0.5 秒）再发。
- 某块失败（连不上、首字超时、断流、key 无效）：这一块已译完的段保留，不再发新块；等在途的块都结束后，没译完的段一起交给下一层。主服务的连不上 / 超时 / 断流 / key 无效会让它熔断（`breaker`，默认 60 秒内直接走下一层）；格式错误或备用层失败不会。
- 超时默认值（秒）：连接 6、首字 10、断流 20，备用服务同样；腾讯连接 6。
- 代价：每块只看得到自己那几段，同一术语在不同块里的译法偶尔不一致；需要统一的词请写进术语表。腾讯一次批量返回，不分块。
- 主服务地址是局域网/本机的 IP 字面量（如 `192.168.x.x`、`127.0.0.1`）时自动绕过系统代理；写成主机名则不会，需要时请设置 `NO_PROXY`。

### 腾讯交互翻译

- 免 key、不用注册。**全新安装默认关闭**，在 设置 → 翻译服务 勾选后才启用；开着时识别出的文字会发到 `transmart.qq.com`，启动和每次按快捷键时还会连一下该站点预热（不带文字），自检会发一句固定测试句。
- 兼容旧版本：只有**旧格式**（`[vllm]`/`[fallback]`，没有 `[primary]`/`[backup]`）的配置**没写** `[tencent] enabled` 时按**开着**算（那时就是这样默认的，升级后不会悄悄没了兜底），迁移时写成显式的 `enabled = true`。**新格式**的 `config.toml` 没写 = 关（手写的最小配置不会在主服务失败时悄悄把文字发给腾讯）；程序自己保存的 `config.toml` 一向显式写出 `enabled`。
- 整张截图的段落一次提交，整批一起回来（不是逐字流式）。本机实测：一句话首次约 4.5 秒（含建立连接），连接复用时约 1 秒；整块论文段落 3～4.5 秒。
- 这是腾讯网页版用的**非官方接口**，随时可能失效。失效时这一层报错、显示原文（「翻译服务不可用」），不会卡死；自检里「腾讯翻译」一项会变 ❌，这时可以在设置里关掉它。
- 术语表**只支持「保持原样」**（只写一个词的条目）；**不支持「指定译法」**，领域提示也不起作用。机器翻译，学术长句的质量不如大模型；配了主服务或备用服务时它们优先。

## 术语表

设置 → 术语表（也可以直接编辑 `术语表.txt`，文件要存成 UTF-8）。一行一条：`attention => 注意力` 指定译法；只写 `ImageNet` 表示保持原样。改完不用重启，下一次截图就生效。术语表对主服务和备用服务完整生效（术语表和领域提示都写进提示词）。

编辑器会**保留你写的注释（`#` 开头）、分组标题和空行**，保存后还在。保存时做四类检查：

1. 格式错误（**不能保存**）：原文为空、原文以 `#` 开头或含 `=>`、原文或译法里有换行；
2. 原文重复（警告，确认后可保存）；
3. 同一个译法对应多个原文（警告：中译英时有歧义）；
4. 译法只有一个汉字（警告：中译英时会误伤正文）。

这是你自己的本地文件，不进 git。编码不对时托盘会提示，程序照常运行（启动时先用空术语表，截图时沿用上一份）。

## 出问题时

1. 托盘「自检…」：逐行检查 OCR 英文语言包、OCR 中文语言包、配置文件、主服务、备用服务、腾讯兜底、快捷键、字体，⏳ → ✅/❌。有问题的行带修复按钮（如「打开设置」「打开系统语言设置」）。
2. 「复制结果」可以直接发给别人求助：key 已打码成 `sk-…末4位`。
3. 命令行版：先进入仓库根目录，运行 `python -m shotrans.doctor`；检查别处的数据目录用 `python -m shotrans.doctor --home <数据目录>`。
4. 日志：`%APPDATA%\截图翻译\logs\shotrans.log`（托盘「关于…」里也有「打开日志」）。程序内部的意外错误也记在这里，同时托盘弹「程序内部出错了」（30 秒内最多弹一次）。
5. 译文看着不对：点浮窗工具栏的「导出」，会在 `debug\<时间>-<编号>\` 存下原图、当前译文图和 `snapshot.json`（识别结果、译文、排版参数，不含任何密钥），之后用 `python -m tools.replay <文件夹>` 离线复现排版。原图是屏幕内容，可能含私人信息，别随意外传。
6. 历史记录在托盘「历史记录…」：最新的在最上面，可搜索（只搜文字）、删除单条、清空全部（有二次确认）。选中一条，上方显示这次的译文图，「看原图 / 看译文图」按钮切换（比窗口宽时按宽度缩小，太高可滚动）；下方照旧是原文 / 译文和复制按钮。没存截图的记录只显示文字；刚翻完、图还在后台写时显示「截图正在保存…」，写完自动显示出来。

## 界面语言

中文 / English，设置 → 常规里切换，立即生效。发给大模型的提示词不随界面语言变化。

## 已知限制

- 托盘「退出」不会提醒你设置窗口里还有没保存的修改。
- 在 `config.toml` 里手写的注释，从设置窗口保存一次后就没了（程序重写整个文件）；保存前的上一版留在 `config.toml.bak`（只留一份）。
- 自检窗口里已显示的结果文字不会随界面语言切换而变，点「重新检查」后才变。
- 最早期的启动弹窗（读配置之前，比如“已在运行”）只有在 `config.toml` 能读出来时才会跟着配置的语言走，读不出来就用中文。
- 预设里的服务地址、模型名、价格说明是 2026-10-14 核实的（见上文），之后各家改版不会自动跟上，请以官网为准并自行修改。
- 源码里的 `licenses/` 只有说明文件和 LGPL-3.0、GPL-3.0 全文；各依赖自己的许可证文本在打包时才收集进发布包（见下文「打包发布」）。「关于」里的「查看 LGPL-3.0 全文」依赖它。

## 开发

以下命令都在仓库根目录里运行（`python` 指 conda 环境 `shotrans` 里的 Python 3.12，见上文「第一次使用」）。

- 全量测试：`python -m pytest -W error -q`
- 窗口测试另用 offscreen 再单独跑一遍（`QT_QPA_PLATFORM` 必须在 `QApplication` 创建前设好，所以只能整进程切换）：
  ```powershell
  $env:QT_QPA_PLATFORM='offscreen'; python -m pytest tests/test_ui_*.py -W error -q; Remove-Item Env:QT_QPA_PLATFORM
  ```
- **测试一律通过 `SHOTRANS_HOME` 指向临时目录**（`tests/conftest.py` 有自动夹具），绝不碰真实的 `%APPDATA%\截图翻译` 和真实的「启动」文件夹。
- 对比测试：`python -m tools.make_bench` 生成测试图，`python -m tools.run_bench --stage ocr|full` 出报告到 `bench/out/report.md`（用例见 `bench/cases.toml`；`full` 走和托盘程序同一套服务链）。PDF 用例要的 PDF 不进 git，按 `cases.toml` 开头的说明自己放进 `bench/pdfs/`（`pdf` 写相对路径时按 `bench/` 解析）；生成的图片、真值、报告也都不进 git。`run_bench` 读的配置和术语表和托盘程序一样——数据目录里有就用数据目录的，没有才用程序目录里的旧 `config.local.toml` / `术语表.txt`；想指到别的位置，设置 `SHOTRANS_HOME`。
- 看测试图：`python -m tools.show_bench`，逐张 1:1 显示 `bench/images/`，←/→ 翻页、Esc 退出。
- 和有道盲评：`python -m tools.blind make` 生成 `bench/out/blind.html`；评完把结果存成 `bench/out/blind_answers.json`，再 `python -m tools.blind score` 统计「不比有道差」的张数。

## 打包发布

把程序打成绿色版 zip（解压即用）。同样在仓库根目录里运行。

- **前置**：先装 `requirements.txt`，再 `python -m pip install -r requirements-build.txt`（PyInstaller，版本钉死）。
- **命令**：`python -m tools.build_release`。不用先激活 conda 环境：脚本给 PyInstaller 的 PATH 只放运行它的那个 Python 所在环境的 `Library\bin`、环境根和 `DLLs`，并去掉其它 conda 目录，打完再逐字节核对包里每个 DLL 与该环境里的同名文件一致（否则失败，曾因 PATH 上的 base conda 混进 OpenSSL 3.0、打包版 HTTPS 全坏）；自测也新增 `stdlib-native` 一行，实际加载 ssl/CA 证书包、httpx、hashlib、lzma、bz2、expat、ctypes。
- **产物**（都在 `dist/`，不进 git）：
  - `dist/截图翻译/`：打好的文件夹（`截图翻译.exe`、`使用说明.txt`、`LICENSE.txt`、`用临时数据目录启动.bat`、`licenses/`、`_internal/`）；
  - `dist/ShotTrans-1.0.0-win64.zip` 与同名 `.sha256`（文件名用英文：GitHub Releases 会删掉附件名里的中文；解压出的文件夹和程序仍叫「截图翻译」）。
- **它依次做什么**（任何一步失败就停，退出码 1）：
  1. 全量测试 `pytest -W error`；
  2. 重新生成图标，按 `截图翻译.spec` 跑 PyInstaller（随后检查 DLL 来源）（文件夹模式、无控制台）。体积过滤规则在 `tools/bundle_filter.py`：只留 Qt 的 Core/Gui/Widgets 及必需插件，去掉 Qt 翻译、软件 OpenGL、各包的 tests、Pillow 用不到的格式、tkinter/unittest 等标准库；
  3. 复制使用说明、许可证，并从本机已装包里收集各依赖的许可证到 `licenses/third_party/`；
  4. 在**干净环境**里（PATH 去掉 conda、去掉 PYTHON*/QT_* 变量、数据目录指向临时目录）跑 `截图翻译.exe --selftest`；再把整个文件夹复制到一个带空格和中文的路径里重跑一次。任何一行检查失败、或不是打包版（frozen）都算失败；
  5. **个人数据扫描**：整个包（含 exe 里解开的 PKG/PYZ 每个模块）查内网地址、`sk-` 形式的 key（只有 UTF-16 编码的那种写法里，`sk-` 紧贴在英文字母或数字后面的不算，例如 Qt 里连写的时区名 `…Irkoetsk-tyd…`；UTF-8 写法不设这个例外，因为 PYZ 里 key 常量前面那个字节是长度，可能正好是字母或数字）、作者用户路径，以及旧配置 `config.local.toml` 里每个长字符串值（与程序同一项默认值完全相同的除外，比如默认快捷键；对不上默认值的项一律照扫）。命中只报规则名和文件位置，不报值。另外会自证确实解开了 PYZ（条目里必须有 `shotrans.app`）；
  6. 打 zip，超过 50 MB 就失败并列出最大的 20 个文件；
  7. 写 SHA-256。
- **失败时看哪里**：终端最后的「构建失败：…」一段写了是哪一步、哪一项；PyInstaller 的告警在 `build/截图翻译/warn-截图翻译.txt`；自测失败会列出每个失败项的异常。想单独看自测结果，可以手动 `dist\截图翻译\截图翻译.exe --selftest 结果.json`（不建托盘、不占单实例，正在运行的托盘程序不受影响）。
- `--skip-tests`：跳过第 1 步，**只用于调试打包规则**，这样打出来的包不能发布。
- `--legacy-config 路径`：指定旧配置文件（默认仓库根目录的 `config.local.toml`）；文件不存在时打印一行警告，只用固定规则扫描。
- 改了 `shotrans/iconart.py` 的图标绘制，要 `python -m tools.make_icon` 重新生成 `shotrans/assets/icon.ico` 并提交（构建脚本也会重生成一次）。
- 新增 `shotrans` 模块要登记进 `shotrans/selftest.py` 的 `MODULES`；新增文字模块要登记进 `shotrans/texts/__init__.py` 的 `MODULES`（各有测试检查，忘了会红）。
- 改了 `tools/bundle_filter.py` 之后一定要跑一遍真构建，看第 4 步自测是否还过。

## 手工验收清单（每次发版前在真机点一遍）

- [ ] 配置过以后双击启动：右下角弹「已在后台运行，按 快捷键 截图翻译…」，点提示打开历史记录；再双击一次：弹「已在运行，按 快捷键…」的提示框；开机自启（重启电脑）不弹提示。
- [ ] Windows「设置 → 系统 → 通知」整个关掉（或打开勿扰）后再手动启动：右下角照样出现「已在后台运行」小窗；它不抢当前窗口的焦点、任务栏不多出按钮；鼠标停在上面不消失，移开约 6 秒后消失；点 × 只关掉，点其余地方打开历史记录。启动提示还在时立刻按快捷键：框选层里看不到这个小窗（截屏前已藏起）。钉住一个浮窗盖住小窗所在位置后再触发一条提醒（如托盘「重新加载配置」）：新提醒出现在浮窗上面。125%/150% 缩放和多显示器下位置在主屏任务栏上方、文字不被切掉。
- [ ] 用一个空的 SHOTRANS_HOME 启动：自动弹出引导；中途关掉 → 右下角提示「还没配置翻译服务」，点提示重新打开引导；此时按快捷键也是打开引导，不进截图。
- [ ] 引导第 2 步：OCR 两个语言包都在显示两个 ✅；「打开系统语言设置」能打开 Windows 的语言页。
- [ ] 引导第 3 步：选 DeepSeek，不填 key 点「测试连接」→ ❌ API key 无效；填对 key → ✅ 秒数 + 译文；之后「下一步」才可点；再改一个字 →「下一步」又变灰。
- [ ] 引导完成后「现在试一下」直接进入框选，译文正常出现，状态栏显示「主服务」。
- [ ] 托盘菜单顺序与上文「怎么用」一致；左键单击图标是截图。
- [ ] 设置 → 翻译服务：地址填 `api.deepseek.com`（不带 https）点「确定」→ 标红、停在这一页、不保存。
- [ ] 设置 → 快捷键：按下一个被别的软件占用的组合（如有道的 Ctrl+Alt+D）→ 当场标红；换一个可用的点「确定」→ 新快捷键立即可用、旧的失效、托盘菜单文字更新。
- [ ] 设置 → 术语表：注释灰色、分组标题保存后还在；加一条只有译法的行 → 标黄、不能保存；加一条重复原文 → 警告，确认后能保存。
- [ ] 设置 → 常规：切到 English → 托盘菜单、已打开的窗口立刻变英文；勾「开机自启」→ 「启动」文件夹出现快捷方式。
- [ ] 设置 → 高级：改「主服务首字超时」并「恢复默认」→ 回到 10。
- [ ] 手改 `config.toml`（例如改快捷键）→ 托盘「重新加载配置」→ 立即生效；故意写坏 → 提示显示错误原文，旧配置继续用；`config.toml.bak` 是上一次保存前的版本。
- [ ] 自检窗口：逐行 ⏳ → ✅/❌；把主服务 key 改错后重新检查 → ❌ 带「打开设置」按钮；「复制结果」粘贴出来 key 是 `sk-…末4位`。
- [ ] 历史记录：最新的在最上面；搜索译文里的词能找到；选中一条能看到译文图，按钮切到原图再切回；删除一条、清空全部（有二次确认），`history_images\` 里对应的图也没了。
- [ ] 浮窗：右键空白处立即关闭（钉住的也关），右键某段仍弹菜单。
- [ ] 设置 → 常规 取消「保存截图图片」后再截一张：历史里这条只有文字，`history_images\` 里没有新图。
- [ ] 关于：版本号 1.0.0；「打开数据文件夹」「打开日志」可用；「查看 LGPL-3.0 全文」能打开。
- [ ] 断网后截图：状态栏「翻译服务不可用」旁有「设置」链接，点开是设置的翻译服务页。
- [ ] 卸掉中文 OCR 包（或在只装英文的机器上）：中文截图仍能出结果，状态栏注明「未装简体中文 OCR 语言包」。
- [ ] 旧版本用户升级：程序目录有旧 `config.local.toml`、数据目录为空 → 启动后提示「已把旧配置迁移到…」，设置里能看到原来的地址，旧文件没被改动。
